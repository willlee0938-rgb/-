# DriveOS — 中古車 AI 銷售營運工作台

目前版本：V3 原型（單檔 HTML + localStorage）
使用者定位：遠端中古車合作銷售窗口，以 Facebook 社團 / Threads 免費流量獲客，合作車行負責現場賞車、專業說明、簽約與交車。

## 立即執行
直接開啟 `index.html` 即可使用。目前不需要伺服器。

## V3 已有功能
- 營運 KPI 與待辦
- 車源管理 CRUD
- 每台車顯示圖片
- 車輛圖片 URL / 本機上傳（測試用）
- 客戶 CRM 與銷售漏斗
- Facebook / Threads 貼文管理
- 轉介、成交與佣金紀錄
- 簡易數據分析
- JSON 匯出 / 匯入備份
- 響應式介面

## 重要現況
- 現在所有車源均為示範資料，不是真實車行庫存。
- 資料只存在瀏覽器 localStorage，正式版需改為雲端資料庫。
- 尚未串接合作車行網站 / API。
- 尚未具備 AI 自動生成廣告文案。
- 尚未具備 Meta / Threads 發布功能。

## 原則
- 車況、事故、保固、貸款、價格等不得由 AI 捏造。
- 車行資料只在取得合法授權後同步。
- 自動發布只能使用平台官方允許且帳號已授權的方式。
- 不使用繞過平台限制、違反社團規範或大量洗版的自動化。
